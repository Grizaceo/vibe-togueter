# Flow card proposals

`how-it-works.proposal.mmd` proposes the card for the README section "How it works". It shows the current flow: joining by pairing code, playing, and building. VM3 is drawn dashed because it is phase 4 and not built.

To accept it:
1. Review it in ADW Canvas.
2. Save the approved `.adw.json` and `.mmd` in `docs/flows/`.
3. Run `vitrina embed README.md docs/flows/<card>.mmd`. Then update README.es.md and run `vitrina stamp README.es.md`.
